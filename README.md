# 💥 꼬마 포트리스

아이와 함께 하는 2인용 턴제 대포 게임 (웹, 세로 화면).

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

- 같은 와이파이라면 두 기기에서 `http://<컴퓨터IP>:3000` 으로 접속하세요.
- 밖에서도 하려면 Render·Railway·Fly.io 같은 Node 호스팅에 올리면 됩니다 (`PORT` 환경변수 지원, WebSocket 사용).

## 규칙

- 같은 **방 이름**으로 두 명이 입장하면 시작 (기본 방: `main`).
- 서로 맵 양 끝(화면 약 10배 거리)에 위치, 상단 **미니맵**에서 전체를 볼 수 있음 (미니맵을 누르면 그 위치를 잠깐 구경).
- 차례마다 **30초**.
- **왼쪽**을 위아래로 끌어 각도(0~90°) 조절, 왼쪽 아래 **각도기**는 항상 표시.
- 오른쪽 **발사 버튼**을 누르고 있으면 게이지가 0→100으로 차오르고, 손을 떼면 그 힘으로 발사 (흰 선 = 지난번 힘).
- 미사일은 포물선으로 날아가고, 맞은 땅은 파임.
- 체력 100. 탱크 종류(6종)가 무작위로 정해지고 종류별 범위 안에서 공격력/방어력이 랜덤.
- 컴퓨터: ↑↓ 각도, 스페이스 꾹 → 발사.

## claude.ai에서 바로 하기 (서버 없이)

`node tools/build-artifact.js` 로 `dist/artifact.html` 을 만들어 claude.ai 아티팩트로 올리면,
두 기기에서 같은 계정(또는 공유받은 사람)으로 링크를 열고 같은 방 이름으로 입장해 대전할 수 있어요.
먼저 들어온 사람의 기기가 방장이 되어 게임을 진행합니다. "한 기기에서 둘이 하기"도 있어요.
